# AI Agent Templates

Скрипты на Python для автоматического разбора и документирования легаси-кода (в нашем случае - на VBA) с помощью ИИ-агентов. Шаблоны для автоматизации рутины по аудиту старого софта.

## Как устроено:
1. **Фреймворк:** Использую **CrewAI** для оркестрации. Логика последовательная — сначала один агент пишет документацию, потом второй ищет баги и уязвимости.
2. **Конфиги в YAML:** Все промпты, роли и задачи вынес в отдельные файлы `agents.yaml` и `tasks.yaml`. Так проще менять логику и поведение моделей, не трогая сам питоновский код.
3. **Локальный запуск (Ollama):** Чтобы код не улетал в открытый интернет, скрипт общается с локальным сервером **Ollama** по API. Тестировал на модели `qwen2.5:1.5b` — отлично синтаксис старого кода.

## Стек:
- Python 3.10+
- CrewAI
- Ollama API + Qwen2.5

## Быстрый старт:

1. Скачать Ollama и запустить модель в консоли:
```bash
ollama run qwen2.5:1.5b
```

2. Поставить библиотеки в venv:
```bash
pip install crewai pyyaml
```

3. Положить нужный кусок кода в файл `legacy_code.vba` (папка input) и запустить скрипт:
```bash
python crew_yaml_analyst.py
```
(или любой из двух других)

Результаты сохраняются в файл (папка output).
